GitHub Actions are pinned to versions that run on Node 24: `checkout@v7`, `upload-artifact@v7`, `gitleaks-action@v3`, `CodSpeedHQ/action@v5`, `upload-pages-artifact@v5`, `deploy-pages@v5`, and `setup-uv@v10.0.1`. The last is pinned to a full version on purpose: setup-uv stopped publishing floating major tags at v8, so `@v10` does not resolve. CodSpeed v5 also made `mode` a required input, and this job wants `simulation` — counting instructions rather than timing a shared runner is the entire reason the 5% gate means anything.
