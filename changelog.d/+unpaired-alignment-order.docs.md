The roadmap now puts Wasserstein Procrustes ([Grave, Joulin, Berthet, AISTATS 2019](https://arxiv.org/abs/1805.11222)) ahead of vec2vec as the first step toward unpaired alignment. It removes the same limit — fitting an adapter when the old model can no longer be run — and fits the existing code almost exactly: the orthogonal solve is already there and already the winning candidate, the addition is an assignment step, and it runs on CPU without torch. vec2vec's adversarial and cycle-consistency training stays behind it, to be paid for only if the cheaper route fails.
